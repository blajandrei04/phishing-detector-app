# Phishing Detector Web Application

A full-stack, machine-learning-powered web application for detecting phishing and malicious URLs in real-time. This project serves as a bachelor thesis implementation, demonstrating end-to-end applied machine learning, secure RESTful API development, and modern frontend architecture.

## Architecture

The project is split into two primary components:

1. **Python/FastAPI Backend (`/backend`)**
   - High-performance asynchronous API for URL analysis.
   - 22 custom engineered lexical, structural, and heuristic features.
   - Uses an XGBoost classifier trained on a large-scale dataset.
   - Incorporates a secure SQLite database for storing analysis history and administrative feedback.

2. **Angular Frontend (`/frontend/frontend`)**
   - Built with modern Angular 17+ and NgRx state management.
   - Provides a clean, responsive UI for users to analyze URLs.
   - Includes a secure, RBAC-protected Threat Intelligence dashboard for administrators to review and label false positives.

## Key Features
- **Real-time ML Inference:** URL feature extraction and prediction happen on the fly.
- **Explainability:** SHAP-compatible tree-based models provide feature importance to help explain predictions.
- **Interactive Dashboard:** Secure admin portal with real-time statistics and historical scan data.
- **Role-Based Access Control (RBAC):** Authenticated flows to protect sensitive administrative actions.
- **Built-in Documentation:** OpenAPI specifications available out-of-the-box.

## Getting Started

### Prerequisites
- **Python 3.10+**
- **Node.js 18+**
- **Angular CLI**

### Backend Setup
1. Navigate to the backend directory:
   ```bash
   cd backend
   ```
2. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   # On Windows
   .\venv\Scripts\activate
   # On macOS/Linux
   source venv/bin/activate
   ```
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Start the backend server:
   ```bash
   uvicorn app.main:app --reload
   ```
   *The API will be running at `http://localhost:8000`*
   *OpenAPI documentation is available at `http://localhost:8000/docs`*

### Frontend Setup
1. Navigate to the frontend directory:
   ```bash
   cd frontend/frontend
   ```
2. Install Node dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```
   *The application will be running at `http://localhost:4200`*
